\# Lesson 1 — Git \& GitLab Fundamentals



\## What is Git?



Git is a distributed version-control system used to track changes to files and maintain the history of a project.



\## What is GitLab?



GitLab is a DevSecOps platform that provides Git repository hosting along with collaboration, CI/CD, security, package management, and deployment capabilities.



\## Git vs GitLab



| Git | GitLab |

|---|---|

| Version-control system | DevSecOps platform |

| Tracks changes | Hosts Git repositories |

| Works locally | Provides remote repository hosting |

| Uses commits and branches | Provides Merge Requests, CI/CD, security and deployment |



\## Local vs Remote Repository



\### Local Repository



The Git repository stored on the developer's computer.



\### Remote Repository



A Git repository hosted on a remote platform such as GitHub or GitLab.
